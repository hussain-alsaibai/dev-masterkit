## New Repos Added

- **tiny-bulkhead v0.1.0** (NEW repo, hussain-alsaibai/tiny-bulkhead) — zero-dep concurrency isolation. `Bulkhead("openai", max_concurrent=4, timeout=1.0)` rejects the 5th in-flight call after 1 second. `BulkheadPool` registry pattern keeps call sites clean. Async + sync support. 23 tests, MIT, ~290 LOC. The third arm of the resilience family: rate-limiter ("how many per second?"), bulkhead ("how many in flight at once?"), circuit-breaker ("should we call at all?").
- **tiny-feature-flag v0.1.0** (NEW repo, hussain-alsaibai/tiny-feature-flag) — zero-dep feature flag evaluation. Three-valued rule semantics: `True` (enable) / `False` (force off) / `None` (defer to next rule). Built-in rules: `eq`, `ne`, `in_`, `contains`, `matches`, `percent`, `predicate`. Stable SHA-256 percentage rollouts. 28 tests, MIT, ~290 LOC.
- **tiny-middleware v0.1.0** (NEW repo, hussain-alsaibai/tiny-middleware) — zero-dep composable middleware chain for sync/async handlers. Auto-detects sync/async per callable. Built-ins: `request_id()`, `cors()`. Pairs naturally with `tiny-router`. 23 tests, MIT, ~245 LOC.

Quality is out of scope (this is a budget library) but `compare_models()` replaces the hand-rolled "if long use claude, if bulk use gpt-4o-mini" decision with a deterministic sort.

### Developer Tools Landscape 2026-10-13

Four trends documented in reports/2026-10-13-developer-tools-landscape.md (10.0 KB):

1. **Resilience primitives form a three-piece family** — `tiny-circuit-breaker` (failure rate), `tiny-bulkhead` (concurrency cap), `tiny-rate-limiter` (request rate) all ship in this cycle as a coherent set. They answer three different questions and the patterns compose.
2. **Three-valued rule semantics for tiered rollouts** — `tiny-feature-flag` rules return `True` / `False` / `None`. The `None` defer is what makes "pro users always; otherwise 20% of free users" expressible as a flat rule list instead of nested conditionals.
3. **Middleware chains are still the right composition primitive** — `tiny-middleware` ports the Koa/Express pattern to Python with auto-detection of sync/async handlers. A chain with any async callable auto-promotes to async.
4. **LLM model selection is a 3-axis problem** — `tiny-llm-budget` v0.2.0 adds `compare_models()` that sorts candidate models by `fits`, `remaining`, and `cost`. The `COST_PER_MILLION` catalogue covers 22 frontier models with input/output split.
