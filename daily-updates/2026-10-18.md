## New repos (1)

- **tiny-jsonpath v0.1.0** — RFC 9535 (JSONPath 1.0) parser and evaluator, stdlib-only,
  pure-Python, ~830 LOC. Supports root, members, indexing, slicing (all 8 forms),
  wildcard, recursive descent, unions, filter expressions with &&/||/=~. Sidecar-friendly:
  drops in as a single file. 49 tests pass. Pairs with tiny-input-sanitize (jsonpath
  context) for safe querying of untrusted queries.
  https://github.com/hussain-alsaibai/tiny-jsonpath

## Version bumps (2)

- **snapdb v0.18.0** — Query engine integrates HashIndex (equality) and RangeIndex
  (gt/gte/lt/lte). 31.5x speedup on 50K-row narrow range scan (500 matches). New:
  Query.between() shortcut, Query.explain() for plan introspection. 33 new tests, all
  213 tests pass.
  https://github.com/hussain-alsaibai/snapdb
- **fast-cache v0.7.2** — SingleFlightCache protects against cache-stampede. Per-key
  threading.Event so N concurrent misses share one factory call (different keys run in
  parallel). New: SingleFlightCache, SingleFlightStats (loads, shared, waiters,
  peak_waiters). 15 new tests, all 74 pass.
  https://github.com/hussain-alsaibai/fast-cache

  caller for that key. This is the same class of bug as the v0.7.1 CRDT slot bug; both
  require "fail fast, free the slot" semantics on exception. Worth documenting as a
  family-wide invariant.
