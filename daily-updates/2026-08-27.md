## Key Pattern: Fine-Grained PAT Cross-Repo Access

When opening PRs on external repos via fine-grained PAT:
1. The PAT must explicitly list the repo under "Repository access" — even if PAT is scoped to "All repositories"
2. The PAT must have `Contents: Read and write` AND `Pull requests: Read and write` — not just Contents
3. The GitHub Search API (`/search/issues`) also requires the repo explicitly added — not just `/repos/:owner/:repo` endpoints
4. Without this, `gh pr create` → GraphQL "Resource not accessible" and `POST /repos/:owner/:repo/pulls` → 403

See also: `prompts/gitea-cross-fork-pr-blocker.md`, `prompts/bounty-pat-fine-grained-fixes.md`
