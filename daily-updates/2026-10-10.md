### Developer Tools Landscape 2026-10-10 (file: `reports/2026-10-10-developer-tool-trends.md`)

Three patterns documented:

1. **The "envelope" pattern for tool calls** — `tiny-tool-result` joins a growing list of libraries normalizing tool I/O (`tiny-cost`, `tiny-trace`, `tiny-rate-limiter`). Same shape regardless of source type.
2. **The "scope" pattern for runtime containment** — `tiny-agent-scope` sits above `tiny-rate-limiter` (request rate), `tiny-circuit-breaker` (failure rate), `tiny-retry-plus` (transient retry). Answers "should this agent have been allowed to do this at all?" by checking budget AND policy together.
3. **The "manifest" pattern for runtime introspection** — `tiny-skill-loader` is a sibling of `tiny-mcp-server` (MCP servers with manifest tools) and `tiny-mcp-registry` (MCP discovery). All converge on a *manifest* as the unit of self-description.

The full report also includes the **layered stack table** (8 layers, 8 corresponding tiny-* repos) showing that "agent" is now a composition, not a script.
