## Scanner Bug Fix: `alreadyAwarded` check now filters closed issues

**Problem:** The bounty scanner's `alreadyAwarded` check only looked for "awarded" comments on GitHub issues. But on Algora, payouts happen on **merged PRs** — not issue comments. This meant closed issues with paid bounties were still being ranked.

**Root cause:** Algora pays out on the PR, so an issue can be:
- Open + no "awarded" comment → still paid out (PR merged)
- Closed + no "awarded" comment → likely paid out

**Fix applied:** `scanner.js` line 547 — added `issue.state === 'closed'` filter before scoring:

```javascript
// Before: only checked for "awarded" comments
const alreadyAwarded = comments.some(c => c.body.includes('awarded'));

// After: also skip closed issues (Algora pays on PR, not issue comments)
if (issue.state === 'closed') return 0; // Already resolved — skip
const alreadyAwarded = comments.some(c => c.body.includes('awarded'));
```
