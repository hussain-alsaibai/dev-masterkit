## New report (1)

- `reports/2026-10-16-developer-tool-trends.md` — HTTP correctness theme, 3 trends:
  1. **Sliding windows close the boundary-burst hole** that fixed-window counters
     leave open; weighted-prev-window is the simplest algorithm that fixes it.
  2. **Hierarchical quotas need all-or-nothing acquire** — partial reservations
     under-report utilization and break the parent/child invariant. Pair with a
     `blocked_at` diagnostic so the 429 can tell you *which* node hit zero.
  3. **RFC 9457 enforcement > dict literals** — half-implementations of Problem
     Details are everywhere. A small dataclass + a registry is the cheapest way
     to guarantee spec compliance across every error path.
