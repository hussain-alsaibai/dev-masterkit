## New Repos Added

- **`tiny-graceful` v0.1.0** — NEW repo, hussain-alsaibai/tiny-graceful. Zero-dependency cross-platform graceful shutdown for threaded and asyncio services. ~280 LOC, 55 tests (all passing, including an AST test that fails on any non-stdlib import). Shipped `Shutdown` / `AsyncShutdown` (one-shot, idempotent), `@shutdown.hook(priority=N)` (reverse-order LIFO), `coordinator()` context manager (SIGINT/SIGTERM), `serve()` / `async_serve()` (worker pools + shutdown in one call). Design change mid-build: added explicit `shutdown=` parameter to `serve()`/`async_serve()` because the original signal-driven test killed pytest — signal handlers can only install on the main thread, and the parameter is better design anyway (you wire /admin/drain and the test runner onto the same exit path). Verified end-to-end with `timeout -s TERM python3 example.py`: hooks fired in exact reverse order with `StopReason.SIGTERM`. **Last verified 2026-10-20.** https://github.com/hussain-alsaibai/tiny-graceful

## Existing Tools Updated (Verified)

- **`tiny-semver` v0.2.0** (hussain-alsaibai/tiny-semver) — substantial update. 4 real defects fixed, 3 of them silent wrong-answer bugs:
  1. Tilde was major-level range (~`1.2.3` wrongly accepted `1.3.0`). Now patch-level per SemVer/PEP 440/npm.
  2. Caret below 1.0.0 didn't narrow (`^0.0.3` accepted `0.0.4`). Now cascades — major -> minor -> patch.
  3. Pre-release identifiers compared as strings (`alpha.2 > alpha.10`, `1 > alpha`). Now (kind, value) sort keys with numeric vs alphanumeric precedence.
  4. `Version.raw` joined without the dot separator (`100-alpha.2` instead of `1.0.0-alpha.2`).
  - Added: `ConstraintSet`, `parse_range()` for comma conjunctions and `||` disjunctions (v0.1.0 could express neither), `filter_satisfying()`, `find_max_satisfying()`, `Version.precedence`, `is_compatible_with()`, `bump_release()`, `bump_prerelease(stable=True)`, `Constraint` str/eq/hash.
  - 115 tests passing (was 22). Notes: the v0.1.0 test_tilde asserted the buggy behaviour, so that test was corrected rather than the fix, with a comment.
  - **Last verified 2026-10-20.** https://github.com/hussain-alsaibai/tiny-semver
