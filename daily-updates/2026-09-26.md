  - Auto-coerces string values from TOML/INI/env to declared int/bool/list types before validation

  - Raises `ConfigError` on validation failure with full error context

    - `add_rule(check, message)` for imperative predicate registration
    - `Computed(fn)` class attribute for derived fields
    - `add_computed(name, fn)` for imperative registration
    - `CrossFieldError` for explicit error raising
  - 17 new tests (34 total, all passing)
  - Commit: `bd0fb36`

  - Bridges tiny-log to tiny-trace and any OTel-compatible exporter
  - Custom attr names supported (`attr_trace`/`attr_span`)
  - Failing providers don't kill logging (graceful degradation)
  - 15 new tests (32 total, all passing)
