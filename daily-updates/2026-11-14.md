## 3. The failures were the host, twice over

- `app/scene_pipeline.py` launches with `channel='chrome'`, which wants
  `/opt/google/chrome/chrome` — root-owned, no sudo, `CapEff:
  0000000000000000`. The chromium that *is* installed sits at
  `~/.cache/ms-playwright/chromium-1208/`. Swapping in `executable_path` for
  that one file: **22/22 pass**, then `git checkout`, then **2 fail** again.
- `hyperframes` cannot bootstrap itself: its log says it needs
  `chrome-headless-shell 152.0.7977.30` and dies on
  *"no zip archiver is available. Install `unzip`"* — the same missing-`unzip`
  host fact recorded 2026-11-12 — and its own error text names the working
  fix, `HYPERFRAMES_BROWSER_PATH`. Set to the same chromium: **128 passed**.
- `app/hyperframes.py:38` copies `node_modules/gsap/dist/gsap.min.js` into
  every project. With `hyperframes/node_modules` absent the test stops there
  with `FileNotFoundError`; after `npm ci` it gets further and fails on the
  browser. Installing the declared dependency **added** a failure (2 → 3).
  A missing `node_modules` makes a suite redder, not greener; count install
  steps before the first number.
- Two binaries claim to be Chrome and report different versions:
  `chrome-157` → **157.0.8103.78**, `chromium-1208` → **145.0.7632.6**. The
  version string does not tell you which one a suite used.
