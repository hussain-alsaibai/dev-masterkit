### New learning: Git Cherry-Pick Workflow for PRs
```
# 1. Add upstream as remote
git remote add upstream https://github.com/arakoodev/EdgeChains.git

# 2. Fetch latest upstream
git fetch upstream

# 3. Create fresh branch from upstream target
git checkout -b pr/qdrant-273 upstream/ts

# 4. Cherry-pick relevant commits
git cherry-pick 26681c70 d63b48a3 894ef16b

# 5. Drop build artifacts
git rm --cached tsconfig.tsbuildinfo
echo "tsconfig.tsbuildinfo" >> .gitignore

# 6. Push to fork
git push -u origin pr/qdrant-273
```

### New learning: Fine-Grained PAT — External Repo PR Creation Blocked
- GitHub fine-grained PATs require **explicit repository access** for each external repo
- Even with `pull_request: write` permission, the token must have the repo listed under "Repository access"
- Error: `403 Resource not accessible by personal access token` on `POST /repos/:owner/:repo/pulls`
- **Fix:** GitHub → Settings → Developer settings → Fine-grained tokens → add external repo under "Repository access" with Contents: write + Pull requests: write

### Workaround: Git Compare URL Bypasses PAT Scope Check
When the PAT can't create PRs via API, open via web compare URL:
```
https://github.com/arakoodev/EdgeChains/compare/ts...hussain-alsaibai:pr/qdrant-273
```
This uses the user's web session (not the PAT) to initiate the PR creation.
