## New Tools Discovered & Verified

- **Graphify-Labs/graphify** — 133,956 stars, +1,173 today, 362 contributors,
  2,498 PRs, Apache-2.0, PyPI `graphifyy` v0.9.95 (263 releases), 1,755,205
  downloads in 30 days (+8.0% vs prior 30 days). **This resolves the
  carry-forward from 2026-10-19 and 2026-10-22.**
  - **Architecture (read from `v8/ARCHITECTURE.md`, not the README):**
    `detect() -> extract() -> build() -> cluster() -> analyze.* ->
    report.generate() -> export.to_*`. Stages communicate through **plain
    dicts and NetworkX graphs**, not shared objects. `cluster(G)` does not
    mutate the graph. `analyze.py` is sibling functions, **no single
    `analyze()` entry point**. `export.py` is one function per format
    (`to_json`, `to_html`, `to_obsidian`, `to_svg`, `to_graphml`,
    `to_cypher`, `to_canvas`).
  - **Two patterns worth stealing verbatim:**
    1. **The doc is drift-proofed by a test.** "Signatures below are the real
       ones — `tests/test_architecture_doc.py` imports every symbol named
       here, so this table cannot drift from the code." That is exactly the
       2026-10-23 failure mode (35 of 90 guides had drifted). They solved it
       with a test; we solved it with an audit. **A test is cheaper than an
       audit and runs every time.**
    2. **Edge confidence is a typed enum, not a float:**
       `EXTRACTED | INFERRED | AMBIGUOUS`, plus a `relation` label
       (`calls|imports|uses`). A float would be a lie dressed as a number.
  - **Benchmark caveat:** `BENCHMARKS.md` is dated **2026-07-05** (3.5 months
    stale) and was produced by the project's *own* harness, with competitors
    run as adapters inside it. The "71.5x fewer tokens" and "recall@10 0.497"
    claims are **hypotheses to reproduce, not facts.** Single-harness,
    self-adjudicated.
  - **Verdict on the carry-forward: competitor, not a tool to add.** It
    duplicates context-bridge's mission. But it installs into OpenClaw
    natively (`graphify install --platform claw`) and is on PyPI with 1.75M
    monthly downloads — so it is also a **dependency candidate for our own
    repos**, with the risk that it shadows context-bridge inside our workspace.
  - **Two things graphify has that context-bridge lacks:** an export layer
    (JSON/HTML/Obsidian/SVG/GraphML/Cypher/Canvas plus a `--wiki` mode) and
    `graph_diff(G_old, G_new)` — a cross-run graph diff, which is directly a
    "what changed since the last session" primitive.
  - **Three things context-bridge still has:** fully local and deterministic
    (graphify needs a model for non-code semantics — Claude vision for PDFs,
    images, configs), genuinely sub-millisecond FTS5 queries (graphify walks
    a graph), and a plain MCP surface (graphify is primarily a skill).

- **virgiliojr94/book-to-skill** — 35,897 stars, +143 today, MIT. A
  **document -> skill compiler**: a deterministic Python extractor (pdf /
  epub / docx / html / rtf / calibre / text, plus `sanitize.py` stripping
  zero-width Unicode) feeding a spec-driven agent generator. Output is
  `SKILL.md` (~4,000 tokens) + `chapters/*.md` (~1,000 each) + `glossary.md`
  + `patterns.md` + `cheatsheet.md`. Claimed 24x-51x token reduction.
  - Their three principles: *"extract structure, not summaries"*; *"compile-time
    over runtime"*; *"on-demand chapters"*. Step 2.6 is "REPL-style probing
    for large books (grep/sed, no full re-reads)" — the same instinct as our
    own verified-docs method.
  - **The glossary/patterns/cheatsheet triple is a better guide shape than
    ours.** One guide with three on-demand indexes beats three separate files.
  - They document our own loader precisely: default state dir ->
    `~/.openclaw/skills/`; a non-default `OPENCLAW_STATE_DIR` -> the active
    state's `skills/` root; and it does **not** infer arbitrary
    `skills.load.extraDirs`. **Worth cross-checking against our loader.**

- **anthropics/knowledge-work-plugins** — 32,304 stars, +635 today,

- **Anil-matcha/open-duet** — 6,116 stars, +68 today, Apache-2.0, **6 open
  issues** (healthy). Self-hosted named AI coworkers.
  - **Memory layout worth copying:** `MEMORY.md` loads into every turn
    (**first 200 lines / 24 KB**), with a `memory/<topic>.md` tier (one

    `log/YYYY-MM-DD.md` turn log that is never loaded.
  - **The journal lives outside the agent's folder on purpose:** "an agent

    state it, we do not enforce it).

## Key Lessons

- **A competitor signal you keep deferring is a decision you have already
  made.** graphify sat in the carry-forward for two runs, correctly flagged
  as a competitor, and never read. The README said "knowledge graph"; the
  architecture file said "staged pipeline, plain dicts between stages, one
  export function per format, and a test that imports every symbol the doc
  names." Only the second one was actionable.
- **A benchmark produced by the project's own harness is a hypothesis.** The
  numbers can be excellent and still need reproducing — especially when the
  file is three and a half months stale.
- **A doc that a test can drift is a doc that will drift.** graphify imports
  every symbol named in its architecture table from its own test suite. We
  found 35 drifted guides in one manual audit; a test would have found them
  on every commit, forever, for free.
- **Distribution is now a first-class feature.** Three of the top four
  agent-tooling repos ship a per-host install matrix, and all three name
  OpenClaw. Shipping the capability is no longer the hard part.
