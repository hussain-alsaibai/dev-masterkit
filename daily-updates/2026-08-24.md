## Bounty Scanner: Competition Search 403 — PAT Scope Issue Confirmed

The GitHub search API (`/search/issues` for open PR competition counts) returns 403
even with a fine-grained PAT that has `Contents: Read and write` on the target repo.

**Confirmed root cause:** Fine-grained PAT must have the external repo explicitly added
in GitHub Settings → Developer settings → Fine-grained tokens → Repository access,
even if the PAT is scoped to "All repositories."

**Status:** Competition counts show 0 for all candidates. This is a PAT configuration
limitation, not a code bug.
