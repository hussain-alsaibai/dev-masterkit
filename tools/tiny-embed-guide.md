# tiny-embed — Zero-Dependency Text Embeddings (dense + sparse, no PyTorch)

**Repo:** github.com/hussain-alsaibai/tiny-embed
**Install:** pip install tiny-embed
**Last verified:** 2026-08-14

Pure Python embeddings: TF-IDF, bag-of-words, cosine/Euclidean similarity, top-k search, SVD dimensionality reduction, GloVe support. No NumPy or PyTorch.
