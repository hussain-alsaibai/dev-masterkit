# tiny-repl — Interactive Debugging REPL for AI Agent Pipelines

**Repo:** github.com/hussain-alsaibai/tiny-repl
**Install:** pip install tiny-repl
**Last verified:** 2026-08-14

Replay agent runs step-by-step, diff two executions, inspect state, export traces as JSON/markdown. Record tool calls programmatically, interactive command palette, streaming output capture.
