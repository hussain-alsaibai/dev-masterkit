# tiny-pool — Zero-Dependency Worker Pools (ThreadPool + AsyncPool)

**Repo:** github.com/hussain-alsaibai/tiny-pool
**Install:** Copy tiny_pool.py into your project
**Last verified:** 2026-08-14

Bounded ThreadPool (map, lazy imap, submit) and AsyncPool (amap, imap). Clean asyncio integration. Drop-in replacement for ThreadPoolExecutor with lazy iteration and progress tracking.
