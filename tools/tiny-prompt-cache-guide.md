# tiny-prompt-cache — Zero-Dependency Prompt Prefix Cache for LLM Calls

**Repo:** github.com/hussain-alsaibai/tiny-prompt-cache
**Install:** Copy tiny_prompt_cache.py into your project
**Last verified:** 2026-08-14

Cache LLM responses keyed by system prompt + prefix of user message. Three prefix modes (system_only, prefix_words, prefix_chars). TTL, atomic file storage, @cached decorator, thread-safe.
